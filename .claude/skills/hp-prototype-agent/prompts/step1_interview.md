# STEP1 ヒアリング（深掘り付き）

## 進め方
1. まず **Phase A（本質理解）** でビジネスの根幹を把握する。
2. 次に **Phase B（具体要件）** で設計に必要な情報を集める。
3. 各回答に対して **ステップバッククエスチョン** で深掘りし、表面的な回答を本質的な情報に昇華させる。
4. 最後に **Phase C（分析と推薦）** で回答を統合分析し、IA/Theme候補を提示する。

回答が曖昧なら具体例を示して選ばせる。「なんでもいい」「おまかせ」は絶対に受け入れない——必ず選択肢を再提示し、最低限の方向性を引き出す。

---

## Phase A：本質理解（ステップバッククエスチョン）

IA/Themeを選ぶ前に、ビジネスの「なぜ」を理解する。この情報がプロトタイプの説得力を決定する。

### A-1) このHPで一番実現したいことは何ですか？
- 「問い合わせを増やしたい」→ 深掘り：**現在の月間問い合わせ数は？ 目標は？ 今のボトルネックは何だと思いますか？**
- 「採用を強化したい」→ 深掘り：**どんな職種を何名？ 採用競合はどこ？ 候補者が御社を選ぶ一番の理由は？**
- 「ブランディングしたい」→ 深掘り：**今のブランドイメージと、理想のイメージのギャップは何ですか？**

### A-2) 御社の事業を「誰の・どんな課題を・どう解決する」で一文で教えてください。
- 深掘り：**競合と比べたときの、一番の差別化ポイントは？**
- 深掘り：**お客様が御社を選ぶ「決め手」として一番多い理由は？**

### A-3) HPを見た人に、最終的にどんな行動を取ってほしいですか？
- 深掘り：**その行動を取る前に、訪問者が「知りたい」「安心したい」と思う情報は何ですか？**
- 深掘り：**訪問者が行動をためらう理由（不安/障壁）があるとしたら何ですか？**

### A-4) 御社のお客様（ターゲット）はどんな人ですか？
- 深掘り：**その人が情報収集するとき、最初に見るのは何ですか？（検索/SNS/紹介/展示会）**
- 深掘り：**その人が御社のHPに来たとき、最初の3秒で「ここは自分向きだ」と思える要素は何ですか？**

> **分析メモ（エージェント内部用）**：Phase Aの回答から以下を整理してから Phase B に進む。
> - Value Proposition（一文）
> - Primary Persona（1つ）
> - Conversion Goal（1つ）
> - 信頼の壁（訪問者が感じる不安トップ3）
> - 差別化の軸（競合と比べた強み）

## Phase B：具体要件（7問 + 条件付き深掘り）

Phase Aで理解した本質を踏まえて、設計パラメータを固める。

### B-1) 目的（CV）はどれですか？
- 問い合わせ / 資料DL / デモ予約 / 採用応募 / 予約 / IR / その他（自由入力）
- ステップバック：**そのCVに至る「検討ステップ」は何段階ありますか？（例：認知→興味→比較→問い合わせ）**
- ステップバック：**CVの次のステップ（営業フロー）は何ですか？ HPで渡すべき情報のゴールが変わります。**

### B-2) 提供形態は？
- サービス / プロダクト（SaaS等） / 両方
- ステップバック：**料金体系は公開しますか？（公開/問い合わせ後/検討中）——これによりページ構成が変わります。**

### B-3) 情報量は？
- 少（1ページ〜4ページ、文章短め）
- 中（4〜6ページ、必要十分）
- 多（6ページ以上、比較検討のための詳細）
- ステップバック：**訪問者は「じっくり読む派」ですか？「パッと見て判断する派」ですか？——レイアウト密度に影響します。**

### B-4) 信頼（Proof）の必要度は？
- 低（名刺代わり）
- 中（比較検討はされる）
- 高（事例/数字/推薦など強く必要）
- ステップバック（中・高の場合）：**現時点で使える「証拠」は何がありますか？**
  - 導入社数/実績数値/顧客ロゴ/推薦コメント/受賞歴/メディア掲載/資格認定
  - **一番強い「信頼の証拠」を1つ挙げるとしたら？**

### B-5) ターゲットは？
- 経営層 / 現場 / 開発者 / 求職者 / 一般消費者（複数OK）
- ステップバック：**ターゲットが複数いる場合、最優先のターゲットはどれですか？——Hero/CTAの文言をその人に最適化します。**
- ステップバック：**そのターゲットが「信頼できる」と感じるトーン・表現は？（例：データ重視/感情訴求/専門用語OK/平易な言葉）**

### B-6) 素材（アセット）はありますか？
- ロゴ、代表写真、メンバー写真、オフィス写真、ヒーロー画像、プロダクトスクショ、挿絵
- ステップバック：**ロゴのガイドライン（使用ルール/配色/余白規定）はありますか？**
- ステップバック：**コーポレートカラーやブランドガイドラインは存在しますか？（あれば共有してください）**

### B-7) 見た目の好み（トーン/色/ダークモード/アニメーション）
- 洗練/堅実/先進/ポップ/高級/尖り
- 好きなメインカラー（あれば）
- ダークモード：OFF/AUTO/ON
- アニメーション：なし/控えめ/普通/リッチ
- ステップバック：**「このサイトのような雰囲気にしたい」という参考サイトはありますか？（1〜3つ）**
- ステップバック：**逆に「こうはしたくない」というNG例はありますか？——避けるべき方向性を明確にします。**

## Phase C：分析と推薦

### C-1) 回答の統合分析（エージェントが実施）
回答をすべて受け取ったら、推薦の前に以下の分析を行い、ユーザーに共有する。

#### ペルソナ・ジャーニー分析
```
【訪問者像】
- Who：(Phase A-4の回答をもとに具体化)
- Why：(何を探しにHPに来るか)
- What：(最初に知りたい情報 Top3)
- Barrier：(行動をためらう理由)
- Proof：(信頼を得るために必要な証拠)

【理想のジャーニー】
Landing → (最初に見せるべき情報) → (信頼構築) → (比較検討材料) → CTA
```

#### メッセージング方針
```
【キーメッセージ】
- Hero見出し案（3案）：ターゲットの課題を起点にした見出し
- サブ見出し案：差別化ポイントを端的に伝える一文
- CTA文言案：行動障壁を下げる表現

【トーン・ボイス】
- フォーマル度：(1-5)
- 専門用語レベル：(低/中/高)
- 感情訴求度：(控えめ/バランス/強め)
```

### C-2) IA/Theme推薦
- 上記分析を踏まえて、IA候補Top3、Theme候補Top3を提示する。
- 各候補について以下を説明する：
  - **なぜこの組み合わせか**（ペルソナ・ジャーニーとの整合性）
  - **良い点**
  - **注意点・トレードオフ**
  - **必要な入力（この候補を選んだ場合に追加で必要になる情報）**
- 互換性でNGの組み合わせは提示しない。⚠️は注意文を添える。
- **最推薦の1案を明示し、その理由を述べる。**

### C-3) 確認と合意
- ユーザーにIA/Themeをそれぞれ選択してもらう。
- 選択後、以下を最終確認する：
  - 「この構成で、御社のHPに訪れた [ターゲット] が [CTA] に至るストーリーとして違和感はないですか？」
  - 違和感がある場合は、Phase A/Bの該当箇所に戻って修正する。
