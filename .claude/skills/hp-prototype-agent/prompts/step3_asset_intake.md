# STEP3 画像入力（ビジュアル戦略付きアセット回収）

## 進め方
1. **Phase A（ビジュアル戦略の確認）**：画像を集める前に、選択済みThemeとブランドの方向性からビジュアル要件を明確にする。
2. **Phase B（アセット回収 + 品質深掘り）**：各画像について意図と品質を確認する。
3. **Phase C（ビジュアル一貫性チェック）**：集まったアセット全体の整合性を検証する。

---

## Phase A：ビジュアル戦略の確認

画像回収の前に、以下をユーザーと合意する。

### A-1) ビジュアルの役割定義
- ステップバック：**御社のHPで画像が果たすべき一番の役割は何ですか？**
  - 信頼感の醸成（人物写真/オフィス/実績）
  - プロダクトの理解促進（スクリーンショット/図解）
  - 感情的な共感（ストーリー性のある写真）
  - ブランドの世界観構築（統一感のあるビジュアル）
- ステップバック：**競合サイトの画像を見て「いいな」と思ったものはありますか？ 逆に「安っぽい」と感じたものは？**

### A-2) 画像のトーン確認
- ステップバック：**人物写真の雰囲気はどちらが近いですか？**
  - ナチュラル（自然な社内風景） vs スタジオ（ビジネスポートレート）
  - カジュアル（私服/笑顔） vs フォーマル（スーツ/真剣）
- ステップバック：**全体の色味のイメージは？**
  - 明るく白基調 / 深みのあるダーク基調 / 暖色系 / 寒色系 / ブランドカラー基調

---

## Phase B：アセット回収（深掘り付き）

IA Blueprintの `requiredImageKeys` を列挙し、ユーザーに提出してもらう。
各アセットについて、ただ受け取るだけでなく品質を確認する。

### 各アセットの深掘りポイント

#### ロゴ
- ステップバック：**ロゴのバリエーション（横型/縦型/アイコンのみ/白抜き）はありますか？ ヘッダー/フッター/OGPで使い分けます。**
- ステップバック：**ロゴ周辺の余白（クリアスペース）規定はありますか？**
- 品質チェック：SVG形式が理想。PNG/JPGの場合は解像度が十分か確認。背景透過されているか。

#### ヒーロー画像
- ステップバック：**この画像は御社の何を伝えたいですか？——ヒーロー画像はHPの第一印象を決めるため、目的との整合性が重要です。**
- ステップバック：**テキストを重ねる前提の場合、文字が読みやすい領域（暗い/シンプルな部分）は十分ありますか？**
- 品質チェック：横幅1920px以上推奨。テキストオーバーレイとの視認性を確認。

#### 代表者/チーム写真
- ステップバック：**写真の雰囲気はターゲットに合っていますか？——経営層向けならフォーマル寄り、求職者向けならカジュアル寄りが効果的です。**
- ステップバック：**掲載に関して、撮影された方全員の掲載許可は取得済みですか？**

#### プロダクト/サービスの画像
- ステップバック：**スクリーンショットの場合、ダミーデータではなく実際のUI（またはデモデータ）になっていますか？——リアルなデータが信頼感を高めます。**
- ステップバック：**複数画面ある場合、訪問者に最初に見せたい「一番の画面」はどれですか？**

#### お客様ロゴ/事例画像
- ステップバック：**掲載許可を得ているロゴ/事例はどれですか？——未許可のものは使用しません。**
- ステップバック：**ロゴの並び順に意図はありますか？（例：知名度順/業種別/導入順）**

## Phase C：ビジュアル一貫性チェック

### C-1) アセット × Theme 整合性チェック（エージェントが実施）
```
【チェック項目】
□ 画像のトーン（明暗/色温度）がThemeカラーと調和しているか
□ 人物写真の雰囲気がターゲットペルソナに合っているか
□ すべての画像の品質レベルが揃っているか（解像度/プロ撮影 vs スマホ撮影が混在していないか）
□ ダークモード対応時、白背景ロゴなどが問題にならないか
□ ヒーロー画像にテキストを重ねたとき、可読性が確保できるか
```

### C-2) 不足画像の対処方針
画像が不足している場合は、以下の順で対処を**ユーザーと相談して**決定する。
1. **追加で提出依頼**：具体的に「どんな写真を」「どんな構図で」撮影/準備すればよいかガイドする
2. **プレースホルダ代替**：
   - アイコン/イラスト系：shadcn/ui アイコン + ブランドカラー背景で代替
   - 写真系：カラーグラデーション + テキストで代替（ストック写真は使わない）
   - ステップバック：**プレースホルダで進める場合、本番までに写真を用意する予定はありますか？ 用意する場合の撮影ガイドを出力に含めます。**
3. **Theme再選定**：写真前提のThemeの場合は、写真不要なThemeへの切り替えを提案

### 推奨フォルダ（コード資産に同梱する場合）
- `public/assets/logo.*`
- `public/assets/hero.*`
- `public/assets/ceo.*`
- `public/assets/members/<id>.*`
- `public/assets/products/<id>.*`
- `public/assets/clients/<id>.*`
