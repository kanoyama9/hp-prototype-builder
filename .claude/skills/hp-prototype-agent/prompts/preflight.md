# Preflight（生成前 品質ゲート）

以下のすべてのチェックをパスしない場合、生成せずに修正する。
各チェックには「なぜ重要か」の根拠を含め、問題がある場合は具体的な修正アクションを示す。

---

## 1. 入力品質チェック

### 1-1) メッセージの説得力
- [ ] Hero見出しが「ターゲットの課題」を起点にしているか（自社目線の「私たちは〜」ではないか）
- [ ] Hero見出しに曖昧な修飾語がないか（「最先端の」「革新的な」「トータル」→ 具体的な表現に置換済みか）
- [ ] サービス説明が「Before → After」で訪問者の変化を伝えているか
- [ ] 差別化ポイント（Only 1）が明記されているか

> **ステップバック分析**：Hero → サービス → 証拠 → CTA の流れで「なぜこのサービスを選ぶべきか」の論理が一貫しているか、第三者視点で検証する。

### 1-2) CTAの明確性
- [ ] Primary CTAが1つに絞られているか（複数CTAが同等に目立っていないか）
- [ ] CTA文言が具体的か（「お問い合わせ」だけでなく「無料相談を予約する」等）
- [ ] CTA遷移先が明確か（フォーム/メール/電話/外部サービス）
- [ ] CTA周辺に不安解消テキストがあるか（「無料」「3分で完了」等）
- [ ] CTA後のフロー（次に何が起きるか）が訪問者に伝わるか

> **ステップバック分析**：「もし自分がターゲットだったら、このCTAを押すか？ 押さないとしたら何が足りないか？」を自問する。

### 1-3) 必須キーの充足
- [ ] `requiredTextKeys` がすべて埋まっているか
- [ ] `requiredImageKeys` がすべて埋まっている、またはプレースホルダ方針が合意済みか
- [ ] 断定が危険な項目（住所/代表/価格/法務）が推測で記入されていないか

---

## 2. コンテンツ一貫性チェック

### 2-1) ペルソナ整合性
- [ ] すべてのテキストが同じターゲット像に向けて書かれているか
- [ ] 専門用語のレベルがターゲットに合っているか（経営層向けなのに技術用語過多、等）
- [ ] トーン/ボイスが全ページで統一されているか

> **ステップバック分析**：「ターゲットペルソナがHPを上から下まで読んだとき、『これは自分向けだ』と一貫して感じるか？ 途中でトーンが変わって違和感を覚えないか？」

### 2-2) ストーリーの論理性
- [ ] 訪問者のジャーニー（Landing → 理解 → 信頼 → 行動）に沿ったセクション順になっているか
- [ ] 各セクション間の接続が自然か（唐突なセクション切り替えがないか）
- [ ] 信頼の証拠（Proof）が、訪問者の不安を解消する位置に配置されているか

> **ステップバック分析**：「訪問者の疑問が発生する順番」と「情報が提示される順番」が一致しているかを検証する。

### 2-3) 表記統一
- [ ] 社名/サービス名の表記が全箇所で統一されているか
- [ ] 数字の表記（半角/全角、カンマ区切り）が統一されているか
- [ ] 敬体（です/ます）と常体（だ/である）が混在していないか

---

## 3. デザイン品質チェック

### 3-1) アクセシビリティ
- [ ] テキスト/背景のコントラスト比が WCAG AA 基準（4.5:1以上）を満たすか
- [ ] ダークモード時も同様にコントラストが確保されているか
- [ ] フォーカスリング（キーボード操作時の視覚フィードバック）が設定されているか
- [ ] 画像に適切な alt テキストが設定可能か（テキストキーに含まれているか）

### 3-2) レイアウト健全性
- [ ] 空配列のセクションを表示しない設定になっているか（例：`services.items.length === 0` ならservicesセクション非表示）
- [ ] 画像未設定セクションが壊れないか（プレースホルダまたは非表示が正しく動作するか）
- [ ] テキストが極端に短い/長い場合のレイアウト崩れが想定されているか

### 3-3) ビジュアル × Theme整合性
- [ ] 提出された画像のトーンがThemeカラーと調和しているか
- [ ] 品質レベルの異なる画像が混在していないか
- [ ] ヒーロー画像のテキストオーバーレイの可読性は問題ないか

---

## 4. 最終ステップバック（生成直前の自問）

生成コマンドを実行する前に、エージェントは以下を自問する。不合格項目が1つでもあれば、該当箇所に戻って修正する。

```
□ このHPを見た [ターゲット] は、3秒で「自分向けだ」と感じるか？
□ [ターゲット] が抱える課題に対して、明確な解決策が提示されているか？
□ なぜこの会社を選ぶべきかの「理由」が、証拠付きで伝わるか？
□ CTAに至る心理的障壁が十分に取り除かれているか？
□ 全体を通して、1つのストーリーとして読めるか？（ツギハギ感がないか）
□ 推測で書いた情報が1つもないか？
```
